Pourquoi OpenCam surpasse les solutions existantes

Conçu dès la première ligne en Rust natif pour éliminer la gigue de buffer, préserver l'autonomie du téléphone et offrir une image digne des caméras dédiées.

Latence < 20 ms (UDP Drop-on-Late)

Contrairement aux applications TCP qui accumulent du retard dès qu'un paquet subit une micro-coupure Wi-Fi, notre réassembleur UDP élimine automatiquement les trames obsolètes. Le flux reste toujours synchronisé avec votre voix.

Protocole binaire 32-octets "OCLV"

Center Stage & Auto-Zoom par Distance

Grâce au calcul de cadrage en temps réel, la caméra suit vos mouvements de tête avec un amorti cinématographique doux. Si vous reculez dans votre pièce, le zoom s'ajuste dynamiquement pour conserver le cadrage idéal.

Sous Linux, OpenCam injecte directement les trames dans /dev/videoX via v4l2loopback au format standard YUYV. Compatible sans aucun plugin avec Discord, OBS Studio, Google Meet, Zoom et Teams.

Compiler et Lancer OpenCam en 2 minutes

1

Créer le device virtuel v4l2loopback (Linux)

Chargez le module noyau Linux pour créer le périphérique webcam virtuelle accessible par OBS et vos navigateurs :

sudo modprobe v4l2loopback video_nr=10 card_label="OpenCam Studio" exclusive_caps=1
2

Lancer la régie Desktop OpenCam

Exécutez le récepteur Desktop. L'annonce mDNS sur _opencam._tcp.local démarre automatiquement :

cargo run -p app-desktop --release
3

Compiler l'APK Android (ou iOS)

Générez la bibliothèque partagée native NDK avec cargo-ndk pour Android :

cd crates/app-mobile/android && ./build-android.sh
